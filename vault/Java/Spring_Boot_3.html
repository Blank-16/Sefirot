Spring Boot 3 Architecture and Features

Spring Boot 3 represents a generational shift in the Java enterprise ecosystem, building on Spring Framework 6 and requiring Java 17 as a minimum baseline. It standardizes on Jakarta EE 10, provides native compilation via GraalVM Ahead-Of-Time (AOT) processing, and introduces unified observability.

1. Core Architectural Shifts in Spring Boot 3

  • Java 17 Baseline: Full leverage of Java 17+ language constructs, including records for DTOs, switch pattern matching, text blocks, and virtual thread execution (Java 21).
  • Jakarta EE 10 Migration: Complete transition from the legacy javax.* package namespace to jakarta.* across all APIs (Servlet 6.0, JPA 3.1, Bean Validation 3.0).
  • Ahead-of-Time (AOT) Engine: Pre-computes Spring bean definitions, proxy evaluations, and reflection registrations at build time, eliminating runtime reflection overhead.
  • GraalVM Native Image Support: Direct compilation to standalone native platform binaries, providing startup times under 50 milliseconds and drastically reduced memory footprints for cloud deployments.

2. Key Framework Modules

  • Spring Web (MVC & WebFlux):
    • Spring MVC: Synchronous, blocking servlet-based web layer running on Tomcat, Jetty, or Undertow.
    • Spring WebFlux: Non-blocking, reactive web runtime powered by Project Reactor and Netty.
    • HTTP Interfaces: Declarative HTTP clients using @HttpExchange annotations, reducing boilerplate for REST consumption.
  • Spring Data JPA: Automated repository generation, dynamic query execution, and seamless persistence mapping built atop Hibernate 6.
  • Spring Security 6: Functional component-based security configuration chain using SecurityFilterChain bean definitions, standardizing on stateless OAuth2/JWT workflows.

3. Observability and Production Readiness

  • Unified Observation API: Replaces disparate instrumentation with Micrometer Observation, generating both metrics and distributed tracing from a single instrumentation point.
  • Tracing Integration: Native support for OpenTelemetry, W3C Trace Context, and Zipkin without requiring separate Sleuth libraries.
  • Spring Boot Actuator: Operational endpoints exposing application health, runtime metrics, environment configs, and Prometheus scrape endpoints via /actuator/*.

Spring Boot 2 vs Spring Boot 3 Comparison

Capability Spring Boot 2.x Spring Boot 3.x
Minimum Java Version Java 8 (Java 11 recommended) Java 17 (Supports Java 21)
Enterprise Namespace javax.* jakarta.*
Native Image Support Experimental (Spring Native) Native GA (GraalVM AOT built-in)
Observability Spring Cloud Sleuth + Micrometer Micrometer Observation (Built-in tracing)
HTTP Client RestTemplate / WebClient Declarative @HttpExchange / RestClient
